# Matsumoto Boundary Official Website

Official website for Matsumoto Boundary, hosted with GitHub Pages.

- Custom domain: [matsumotoboundary.com](https://matsumotoboundary.com/)
- Main app: Construction Calc & Estimate（関数電卓+見積　建築・土木）
- Stack: static HTML and CSS, with no external build dependencies

## Structure

- `/` — Home
- `/apps/` — Apps
- `/support/` — App support
- `/privacy/` — Privacy Policy
- `/contact/` — Brand contact

## Privacy and repository safety

No private user or customer data should be committed to this repository. Do
not commit personal addresses, phone numbers, account credentials, purchase
information, application data, or other confidential material.
